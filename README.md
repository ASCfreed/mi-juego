# Partículas RA

Simulador de partículas subatómicas en realidad aumentada para Android (Unity 6 + AR Foundation + ARCore).

- Documentación completa: [BIBLIA.md](BIBLIA.md)
- Se compila en la nube con Forja3D (plantilla `basica`): `Forja3DBuild.BuildAndroid` llama a `Forja3DPreparar.Preparar()`, que activa el Input System y ARCore, configura el Player y genera la escena.
